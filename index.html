c4-from-code

A Claude Code skill that draws a C4 architecture diagram set, system context, containers and components, from a codebase treated as ground truth, with a verification pass against the source.

  • The worked example: ClassroomIO, a navigable set with drill-down from the system to its containers and components.
  • How to install and use the skill (the repository's README).
  • The example's report: what was verified against the code and where each label comes from.

Install in Claude Code: /plugin marketplace add klauseduard/c4-from-code, then /plugin install c4-from-code@klaus-tools.
